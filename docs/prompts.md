# Instructions sent to the language models

All text below is generated by `scripts/kodowanie_llm.py` (constants `ZASADY`, `ETAPY`, `POJECIA`, `SCHEMAT`) and is reproduced here verbatim, in Polish, as sent to the models. The instruction for initial coding (stage `otwarte`, Claude Haiku 5.5) and for control coding (stage `kontrolne`, DeepSeek V4.1 Flash) is identical.

SHA-256 of the instruction for stages `otwarte` and `kontrolne`: `d40fec92039cca09e9b9e0a2a9169859163b99434c0eae96ee65970d88dd1992`. The same value was computed from the field `instrukcja` stored with every coding result of the study (28 files: 14 transcripts × 2 stages), so the text below is the instruction that was actually used.

## Instruction (stages `otwarte` and `kontrolne`)

```text
Jesteś asystentem kodowania w badaniu jakościowym (konstruktywistyczna teoria ugruntowana, Charmaz 2006): wywiady pogłębione z pracownikami bibliotek akademickich o pracy z metadanymi i AI. Proponujesz kody; badacz zweryfikuje każdy.
Zasady:
- Koduj wyłącznie tury oznaczone KODUJ (wypowiedzi rozmówcy). Tury badacza [B] są tylko kontekstem.
- Fragment ma od jednego zdania do krótkiego akapitu. Pole "cytat" to dosłowny, ciągły fragment tury, bez skrótów i zmian.
- Od 0 do 3 kodów na turę; pomijaj tury bez treści analitycznej (potwierdzenia, formułki).
- Pole "pojecie": identyfikator pojęcia uwrażliwiającego (PB1-PB4, W1-W7), gdy fragment wyraźnie go dotyczy, w przeciwnym razie "brak". Pojęcia wskazują kierunek uwagi; nie dopasowuj na siłę.
- Pole "memo": jedno zdanie analityczne: co rozmówca robi lub jakie znaczenie konstruuje w tym fragmencie.
- Nie dopowiadaj faktów spoza tekstu.
Zwróć wyłącznie JSON: {"kody": [{"tura": "T017", "kod": "...", "cytat": "...", "pojecie": "PB1", "memo": "..."}]}

Etap: kodowanie wstępne (otwarte). Czytaj turę po turze, blisko danych. Kod to krótka fraza w formie rzeczownika odczasownikowego (gerundium), np. "kwestionowanie wiarygodności automatycznych opisów", "negocjowanie granic własnych kompetencji". Dozwolone kody in vivo: słowa rozmówcy w cudzysłowie. Nie narzucaj kategorii z góry.

POJĘCIA UWRAŻLIWIAJĄCE:
PB1: warunki uznania metadanych tworzonych z udziałem AI za wiarygodne; funkcja strażnika jakości (gatekeeper); autorytet poznawczy (Wilson 1983).
PB2: elementy pracy uznawane za niezastępowalne i ich uzasadnienia; jurysdykcja zawodowa (Abbott 1988).
PB3: kompetencje i formy współpracy z AI (narzędzia wdrażane odgórnie i używane z własnej inicjatywy), szkolenia, bariery, szanse rozwoju.
PB4: warunki integracji AI z systemami bibliotecznymi: dostęp do danych, interoperacyjność, uprawnienia i bezpieczeństwo, rola instytucji centralnych i dostawców.
W1: odgórne wdrożenie: asystent AI do katalogowania w Almie udostępniony przez Bibliotekę Narodową.
W2: użycie oddolne, nieformalne (czaty, własne narzędzia).
W3: automatyzacja bez AI jako punkt odniesienia (harvestery, skrypty, współkatalogowanie).
W4: bibliotekarze jako dostawcy danych treningowych i oceniający AI.
W5: ekonomia i etaty.
W6: pokolenia.
W7: dezinformacja i społeczne zaufanie do bibliotek.
```

## Stage text for focused coding (stage `zogniskowane`, implemented, not used in the study)

```text
Etap: kodowanie skoncentrowane (zogniskowane). Przypisuj fragmentom kody z listy KODY ZOGNISKOWANE, dosłownie według nazwy. Jeśli fragment jest analitycznie ważny, a żaden kod nie pasuje, zaproponuj nowy kod w formie gerundium z przedrostkiem "NOWY: ".
```

When this stage is run, the instruction is extended with the line `KODY ZOGNISKOWANE:` and the list from `kodowanie/kody-zogniskowane.md`.

## Message assembled for each fragment

The transcript is divided into fragments of about 12,000 characters at interviewer turns, so that a question stays with its answer. Each request contains the instruction, a header, and the turns of one fragment:

```text
<instruction>

WYWIAD: IDI-NN; rozmówca: <participant description from the transcript header>
FRAGMENT n/N:

[T001 | 00:00-00:12 | B, kontekst] <interviewer turn>

[T002 | 00:12-01:05 | R, KODUJ] <participant turn to be coded>

[T003 | 01:05-01:40 | R, wyłączona z kodowania] (treść pominięta)
```

Turns listed in `config/wylaczone-fragmenty.md` are sent as `(treść pominięta)` (content omitted). Interviewer turns are context only.

## Output schema (JSON Schema, enforced by the API)

```json
{
 "type": "object",
 "additionalProperties": false,
 "required": [
  "kody"
 ],
 "properties": {
  "kody": {
   "type": "array",
   "items": {
    "type": "object",
    "additionalProperties": false,
    "required": [
     "tura",
     "kod",
     "cytat",
     "pojecie",
     "memo"
    ],
    "properties": {
     "tura": {
      "type": "string"
     },
     "kod": {
      "type": "string"
     },
     "cytat": {
      "type": "string"
     },
     "pojecie": {
      "type": "string"
     },
     "memo": {
      "type": "string"
     }
    }
   }
  }
 }
}
```

The script rejects proposals for turns outside the `KODUJ` list and locates each quotation in the turn as exact (`dokładny`), approximate (`przybliżony`: punctuation or ellipsis differences), or not found (`nieznaleziony`: the whole turn is marked for correction by the researcher).
